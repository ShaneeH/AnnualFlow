Annualflow

An open source project by Shane Hahesy that turns financial report PDFs into structured data.

Upload a company's report and the key figures are extracted, checked and stored by company and period. You can then compare periods on a dashboard and export a short board report.

Who it's for

Annualflow is for anyone with a folder of messy financial reports who wants the figures clean and in one place. Drop in your reports and it pulls out the key figures, lines up the periods and gives you back a tidy PDF, Excel or JSON file.

For now it reads PDF financial reports, such as annual and interim reports, not receipts or scanned images. It's open source, so you can see exactly how every figure is handled.

How Data Enrichment works

If you upload a second document for a company and period that already exist, it updates the existing record. Annualflow does not create a duplicate.

Example: two FY2024 documents for the same company
Field First upload Later upload Stored record
Revenue210.7m210.7m210.7m
Net profit24.4m24.6m24.6m conflict flagged
Cash-48.9m48.9m gap filled
EPS-0.610.61 gap filled
  • Empty fields are filled. A value missing from a later document never erases a stored one.
  • If a value differs, the newer one is kept and the change is reported after the upload.
  • Each period keeps a link to every document it came from.
