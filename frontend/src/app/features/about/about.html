Why use Report Hub?

From lengthy PDF to useful financial insight

Company reports contain valuable information, but finding and comparing it can take time. Important figures are often buried across hundreds of pages and presented differently between companies.

Report Hub turns those documents into structured financial data, making it easier to understand performance, compare reporting periods and identify important changes.

Capabilities

Everything needed to analyse a report

1

Automatic extraction

AI assisted analysis identifies the company, reporting period and important financial values directly from the uploaded report.

2

Financial calculations

Revenue growth, margins, liquidity, leverage and other board level performance indicators are calculated automatically.

3

Period comparison

Compare financial periods side by side to quickly identify improvements, declines and wider performance trends.

4

Structured storage

Extracted information is validated, normalised and stored in PostgreSQL for consistent access across the platform.

5

Duplicate protection

SHA256 document fingerprinting prevents the same financial report from being processed more than once.

6

Interactive dashboard

Key values, comparisons and financial ratios are presented through a focused interface built for quick understanding.

Data Enrichment

One record per company and period, however many documents you upload

When a new document covers a company and period that already exist, for example a FY2024 results announcement followed by the full FY2024 annual report, Report Hub enriches the existing period record rather than creating a duplicate. In one database transaction it:

  • Matches the company by name, case-insensitively, and the period by its code (e.g. FY2024, Q3_2025).
  • Fills gaps: each field is merged with COALESCE(new, existing). Figures the new document provides are written. Figures it leaves out keep their stored value and are never erased.
  • Flags conflicts: if both documents give different values for the same field, the newer value is kept and the upload response lists a conflicts[] entry with the period, field, previous value and new value. The app shows these after the upload.
  • Keeps the sources: the document_periods table links each period to every document that contributed to it, so one period can have several source documents. The dashboard shows the count and an Enriched badge.
  • Refreshes derived data: margins and ratios are recalculated from the merged figures, and any cached AI Insight for that period is cleared so it can be regenerated.

Why it matters

  • Single source of truth: one row per company and period, so KPIs, charts and comparisons never double count.
  • No duplicates: the same file is refused by its SHA-256 hash, and different files for the same period merge instead of piling up.
  • Traceable sources: every figure's period knows which documents fed it, and changed values are reported rather than silently replaced.
